# 惯性点击行进与到达反馈
基准：[V1.5](../product/云走标毅线_需求变更记录_V1.5.md)。

## 已选方案
对比过“每次点击固定迈步”和“连续点击增加速度，停止点击逐渐减速”。用户选择后者，强调连续、具有惯性的控制感。

侧栏提供自动/点击切换，自动保持原步调。点击模式显示速度条和“连点加速，松手减速”，地图下方提供可点按的加速按钮，手机与键盘也能使用。地图空白点击同样有效。切换不回起点，切到点击先静止等待操作。

## 首版手感参数（实现取值，可后续调节）
每次有效点击增加3虚拟米/秒，上限12虚拟米/秒；持续以4虚拟米/秒²减速，满速松手约3秒停下。两次有效点击至少间隔70毫秒。路线位置平滑更新，实际移动才累计时间。窗口隐藏、退出、切换模式清空惯性，恢复时不会跳跃。

## 到达反馈
沿线标记投影到现有示意路线以统一位置与里程；背景景点不触发。越过地标即视为抵达，不能因为单帧跨过而漏掉。多个到达按线路顺序排队，每条气泡约4秒，可手动关闭，点位短暂高亮。提示音为本地合成双音，可关闭；浏览器不允许发声时仍显示视觉反馈。

到访在保存进度时一并记录；旧存档按已有进度标记历史到访，恢复不补播。有效时间改为独立累计，避免切换速度后用距离反算时间。浮点误差不能影响终点保存。

## 输入与布局
位移超过8屏幕像素视为拖动，多指手势及取消事件不算点击；第二指按到人物、按住时滚轮缩放也取消点击候选。人物、按钮、地图缩放控件保留原有用途。地图底部固定预留88px作为反馈/操作区，人物画布不延伸到此区域，提示不弹强制对话框；手机使用紧凑反馈。昵称标签避开顶部地图工具和右下缩放工具。减少动态效果设置下关闭装饰动画。

## 超越反馈（用户追加）
比较自己及其他山友在同一帧前后的路线进度：自己原本在后方、现在超过正在前进的山友才触发。刷新恢复、地图缩放和超过已完赛人物均不触发。自己显示短暂光圈，气泡显示对方昵称；2.6秒内连续超越合并为一条，优先显示地标到达气泡。超越提示不发声，避免连串提示音干扰。
