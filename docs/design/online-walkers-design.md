# 真人同行交互设计

基准：[V1.7 真人同行](../product/云走标毅线_需求变更记录_V1.7.md)。沿用 V1.6 的地图与底部操控布局。

## 进入地图

默认入口首次打开昵称卡片，说明分享范围和本机保存边界。提交昵称后进入地图，不要求密码或额外登录。创建昵称即可加入房间，开始走路仍由原有出发按钮和倒数控制。恢复用户显示保存位置及“继续上次行走”。

演示入口 `/?mode=demo` 使用同样的昵称与本机进度，入口文案改为“当前为模拟山友演示，不向在线山友分享状态”。它不是另一份个人存档，也不会同时展示真人和模拟山友。

## 在线状态

地图图例展示连接状态，在线人数只计算其他同行者，不包含自己。

| 状态 | 显示文案 | 行为 |
|---|---|---|
| 初次连接或恢复页面 | 正在连接同行地图 | 等待首次有效快照 |
| 已连接、没有同行者 | 已连接 · 等待同行者 | 保留自己的角色和操控 |
| 已连接、有同行者 | 在线同行 N 人 | 显示同一服务的在线人物 |
| 请求失败 | 连接断开 · 可继续行走 | 移除远端快照，本机行走可继续，自动重试 |
| 房间已满 | 路线已满 · 等待空位 | 不显示过期同行者，等待自动重试 |
| 演示模式 | 模拟山友 19 人 | 不建立在线连接 |

## 人物与反馈

自己的角色保持橙色；在线山友沿用现有人物、聚合和标签布局。标签显示昵称、有效时间和里程；点击人物后在底部查看步调、时间、里程和“在线山友 · 虚拟里程”。昵称较长时地图标签省略，详情展示完整昵称。

收到他人更新后，用约500毫秒插值平滑位置和累计时间。未移动者不播放持续走路动画；用户离开后移除其人物，详情中已不存在的成员也不继续展示。超越反馈只针对实际移动的同行者。

## 延续的边界

页面中的“位置”“里程”始终指示意路线上的虚拟进度。在线连接状态不改变个人存储机制；刷新、换地址或换设备的恢复边界在 README 中说明。连接故障不弹阻断对话框，也不要求重新创建昵称。
