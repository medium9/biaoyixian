# 第一阶段地图设计
当前基准：[V1.2需求变更](../product/云走标毅线_需求变更记录_V1.2.md)，优先于V1.1。
- 依据用户截图原创绘制本地SVG示意地图，山地绿色、西湖与钱塘江蓝色、路线紫色。无需外部地图服务。
- 截图左侧裁切、标记遮挡处用简化路径衔接，保留大体走向，地图与节点均为示意。
- 页面地图为主体；侧栏显示24.57km虚拟里程、三档步调、开始操作、模拟人数与个人进度。
- 地图支持拖动、滚轮、按钮缩放、双指缩放及查看全线。中文标签按缩放三级显示。
- 全览时按屏幕距离聚合，点击人数查看成员并放大。显示倍率达到2.0×后，每个山友独立呈现，即使他们走到同一点。
- 相遇时橙色本人留在路线位置，重叠的山友图标向旁边错开，用短虚线指回路线位置。昵称标签跟随图标重新避让，点选仍可查看个人信息。错位仅用于显示，位置、里程和超越判断仍由路线进度计算。
- 页面显示“标毅线示意路线”“依据参考图绘制”，不伪装实测路线或真实在线人数。
- 移动端地图与控制面板上下排列，不要求注册。


## V1.3 当前交互
首次创建本机昵称 → 确认老和云起及步调 → 3秒倒数 → 沿线移动。橙色自己独立显示，可定位；19个模拟山友在打开地图后自动移动。放大可见小人动画。头顶标签含昵称、有效时间、虚拟距离，按屏幕空间避让；标签与人物分层，人物始终在上。

极密集小视口未能放置的标签通过点击人物信息查看。缩小仍以人数聚合，放大展开。不添加领地业务。

## V1.4：离开后继续
重新进入已出发的身份时显示“接着上次，继续走”与“继续上次行走”，恢复原时间和位置；已完成则显示到达终点。继续按钮直接恢复，不重新倒数或更换步调。自己的角色不因刷新增加。存储异常显示重试读取操作。

## 地图整体感调整（2026-11-20）
根据用户“色块拼接、缺少整张地图的感觉”的反馈，底图采用统一的浅灰绿色陆地底色，山体通过大范围透明渐变相互融合，不再用硬边多边形分区。

- 低对比、自然弯曲的等高线替代重复三角山纹；仅作视觉示意，不表达真实海拔。
- 城市道路以连续曲线沿外围铺开，山间小径更细更淡，取消规则方格铺满山地的效果。
- 西湖与钱塘江使用相近水色、柔和岸线，补充湖堤和小岛，形成可辨认的整体地理背景。
- 紫色路线、橙色本人和其他人物保持前景辨识度；地理大字降低对比，避免争抢视线。
- 本次仅调整底图和地图文字样式；路线数据、地标位置及虚拟里程保持原版本。

已检查桌面全景、放大视图和390px手机布局；验收截图保存于tests/artifacts/。

## V1.6 底部操控

桌面底栏上方展示引导、进度与下一处路标，下方放行进与地图按钮。手机端分行显示，主按钮可直接触达。到达与超越提示临时占用路标区域，人物详情通过底部展开。地图专注显示山路与人物，保留小型图例，地名在屏幕边缘向内排布。

底图加入龙井茶坡、林地、城市支路和雷峰塔、水纹、游船等低饱和细节。线路白边、主线与已走路段使用同一缩放系数，标记与名称保持屏幕尺寸。底图细节使用可辨识的地理要素，未经核实的地点应省略。

外围沿用连续底色。钱塘江的示意岸线延伸到拖动范围之外，两岸道路顺势衔接。拖动、缩放和视口尺寸改变时约束地图中心，避免一路拖进空白画布。

普通山友卡片使用透出底图的浅色背景，填充不透明度为72%。昵称、时间和公里数保持实色，橙色本人卡片继续保持不透明。
