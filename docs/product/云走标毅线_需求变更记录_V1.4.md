# V1.4 本机身份的行走记录
日期：2026-11-19。用户要求退出后保留行走时间与位置，避免每次进入重新创建人物。本版本覆盖V1.3中“只保存昵称，不保存进度”的限制。

- 同一本机身份、同一路线版本只有一份当前行走记录，以身份ID和路线标识关联，覆盖更新而非追加。
- 记录模式、已走虚拟米数、累计有效秒数及是否已出发；位置由已走比例映射到路线，不另存容易不一致的坐标。
- 页面正常运行时每秒保存；隐藏页面、离开页面和组件卸载时额外保存。
- 关闭或刷新后重新进入，恢复原位置和时间，等待“继续上次行走”；离线时长不计入。
- 同一页面只渲染一个自己的角色，始终复用身份ID。其他19人为独立模拟数据，不创建虚假在线账号。
- 较旧页面保存不得覆盖较新的进度；继续时重新读取最新快照。
- 已到终点的记录恢复为完成状态，不回起点，不重复出发。
- 本机存储损坏或保存失败时提示，不默默重置；保存失败暂停自己的移动。
- 范围仍为当前浏览器本地数据，不是跨设备账号或服务器数据库。清除浏览器数据会丢失；异常终止可能损失最近约1秒尚未保存的增量。此前未保存的历史行走无法追溯补回。
