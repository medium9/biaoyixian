# V1.3 本机身份与游戏化交互
日期：2026-11-19。基于用户连续确认的调整，保留V1.0–V1.2历史。
- 首次进入创建昵称，使用浏览器localStorage保留身份；无密码、后端及跨设备账号。清除本机数据后需重新创建。
- 起点名称以用户最终更正为准：老和云起。
- 确认起点及步调后3秒倒数出发；仅保存身份，不承诺刷新恢复本次进度。
- 自己使用橙色人物、光圈和昵称标识，独立于其他人的聚合；一键定位自己，行走过的路线橙色显示。
- 19个其他模拟山友在地图打开后沿线持续移动，自己出发前等待。共20个人物，不称真实在线玩家。
- 放大显示二维小人摆臂、迈腿动作；尊重减少动态效果设置。
- 每个独立小人显示昵称、有效行走时间和虚拟距离。模拟人物初始时间依据模式与初始里程计算。
- 标签缩为130×40屏幕像素，避开人物、聚合点与其他标签；优先上方，其次侧方，以细线关联。人物绘制在标签之上；极小视口没有剩余空位时仍可点人物查看详情。
- 借鉴跑步游戏把进度直观呈现在地图上的方式，提供已走路线、下一处路标及倒数反馈；不引入领地争夺、真实GPS、排行榜或付费功能。
- 同类参考：[KYRO官网](https://kyro.team/)，确认其圈地与地图反馈机制；尚未确认它是否就是用户所说的韩国AI开发应用。
