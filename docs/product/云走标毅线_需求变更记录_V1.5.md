# V1.5 双模式行进与地标反馈
日期：2026-11-20。用户选择“连点加速、松手减速”的惯性感。本版本延续V1.4本机身份及行走记录。

- 提供自动行进、点击行进，途中切换共用同一个人物及进度。
- 自动行进沿用跑山、徒步、慢走；点击行进沿路线运动，点击越密速度越高，停止点击后减速直至停止。
- 鼠标与手机点按地图空白处有效；拖动、缩放、点击人物及界面按钮不产生前进操作。
- 抵达沿线地标时提示音、点位亮起及短暂气泡反馈，气泡不阻塞操作，声音可关闭。
- 同一旅程每个地标只提示一次；刷新恢复不补播历史提示。
- 保存控制方式、已到访地标、声音设置；瞬时速度不保存，重开等待继续。旧存档可继续使用。
- 时间累计实际移动秒数，点击停止及离线不累计。虚拟速度不代表真实运动速度。
- 用户追加：超过其他正在行进的山友时也要有反馈。双方沿线位置发生真实前后交换时显示自己的短暂光圈与超越昵称提示；连续超越合并提示，地标反馈优先，不增加排行榜或社交业务。

不增加服务器账号、真实多人、排行榜或领地系统。
