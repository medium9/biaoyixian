# 云走标毅线需求变更记录 V1.1

日期：2026-11-19。基于用户本轮明确提出的路线简化要求；与 V1.0 配套阅读，不复制或覆盖原文。

## 已确认变更：允许示意路线

第一阶段允许参考指定轨迹图，自行描绘大致线路，不再要求精确 GPS 轨迹作为开发或阶段1验收的前置条件。

- 保留参考图的大致走向、起终点和主要节点顺序，允许简化细小转弯及距离比例。
- 路线服务于虚拟徒步体验，不要求与真实山路逐点重合；无需海拔或真实地形高度数据。
- 页面标注“标毅线示意路线”；不能把描绘结果称为精确 GPS 或实测路线。
- 24.57 km 作为虚拟里程基准，跑山／徒步／慢走的3／6／9小时参数保留，不按画出来的线长认定真实公里数。
- 人物必须贴合绘制路线；拖动、缩放、聚合及展开不得改变人物进度。
- 参考图尚未实际查看前，不能声称已按图描绘；继续使用 V1.0 指定来源，不比较其他路线版本。

本记录替代 V1.0 及前期方案中“没有精确真实轨迹就不能完成阶段1路线验收”的限制，也允许有参考依据的近似描绘；其余未涉及需求保持原有范围。

## 数据归属

- `data/routes/verified/`：未来取得的精确轨迹，当前不要求准备。
- `data/routes/schematic/`：产品采用的示意路线，开发时创建，记录参考来源、版本和 schematic 属性。
- `data/pois/`：地标与路线节点，区分真实位置和示意位置。
- `data/mock/`：测试人物和算法测试夹具。正式采用的示意路线不是临时测试夹具，不混放到 mock。
- 不复制供应商地图截图作为产品底图。参考来源与描绘方法写入数据说明。

## 已确认：保留真实杭州底图

用户已明确选择：“保留杭州地图底图，只把路线画成大致示意线”。

- 继续采用高德二维杭州地图，保留真实地理背景、中文地名、缩放及拖动。
- 只简化覆盖在底图上的路线，不开发整张自绘杭州地图。
- 高德Key与服务配置仍需准备；精确GPS文件不再是第一阶段依赖。
- 描绘路线采用与底图一致的坐标系，用于固定示意线位置，不代表测绘精度。
- 沿线节点允许按参考图示意定位；独立文化景点仍采用核实位置，不把周边景点误标为必经节点。

底图选择已解决，设计、技术和开发文档统一采用本方案。
